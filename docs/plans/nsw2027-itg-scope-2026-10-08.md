# NSW 2027 on ITG: scope (2026-10-08)

Pete's priority 2 (2026-10-07). Polling day **13 March 2027** (NSWEC Bulletin 2;
`election_dates()`). Research only; nothing built yet.

## What is settled

- **Boundaries: the 2023 seats.** NSW redistributes after every second election;
  the 2021 redistribution covers both 2023 and 2027
  (https://elections.nsw.gov.au/voters/electoral-districts-redistribution/about-redistribution).
  93 districts. No notional-margin work needed.
- **Polls: one new poll since the trend.** `output/trend-nsw-2027.csv` (19 Sep)
  ends 2026-08-23. The anchor's `analysis/Data/poll-data-nsw.csv` has ResolvePM
  2026-09-01 (ALP 29, LNP 24, GRN 11, ONP 25) after it; upstream (2026-10-07)
  has nothing newer. Trend refresh gains that one poll.
- **Flows:** the anchor's 2027 ONP flow (25.5% to ALP of live, 57.0% exhausted)
  is the federal rate plus the state OTH exhaust rate, not an NSW measurement.
  NSW 2023 measured (Green, 17 seats): 31.0% to ALP of live, 62.2% exhausted
  (`reviews/nsw2027-green-opv-2026-10-07.md`). Our NSWEC transfer file
  (`nswec-nsw-transfers.csv`) can measure it on all seats.

## What is missing

1. **A NSW 2027 seat forecast.** `scripts/fit_seats_full.R` (the published
   script) is hard-wired to Victoria: 63 `vic2026`/`vic2022`/date references in
   1,708 lines, plus four Victoria-only input tables
   (`booth-features-vic2026.csv`, `council-history-vic2026.csv`,
   `senate-vic2026.csv`, `onp-senate-vic2026.csv`).
2. **A provisional candidate list.** Nominations close shortly before 13 March
   2027. Until then: sitting members, announced retirements, the 2023 field by
   party class. The Victorian script already runs on "no candidate list yet"
   fallbacks (DS2/DS3 lines), so this is the same state Victoria was in.
3. **The forecast JSON and ITG page.** `scripts/build_forecast_json.R` already
   takes `AUSPOL_FORECAST_ELECTION`; it needs an `nsw2027` entry. The ITG page
   lives in `inthegame-blog` (another session's repo).

## The decision

A. **Generalise `fit_seats_full.R` to a target election** (`AUSPOL_TARGET`,
   default `vic2026`). One published script for every live election. Cost: a
   refactor of the published path, proven byte-identical on vic2026 before
   anything NSW runs; the four Victoria-only tables become optional with a
   printed "absent for nsw2027" line. Estimate: 1-2 days.

B. **A separate NSW live script.** Faster to a first number, but two
   published scripts drift (CLAUDE.md: "two lists drift in both directions").

Recommendation: A.
