# Every fed2025 preference flow, audited against what we predicted

2026-09-05. Pete: *"do a FULL flow review, check all vote flows for each seat
and see if any are way off and why and fix it."* This is that audit.
`scripts/audit_flow_accuracy.R` compares every actual fed2025 exclusion
against what the model's matrix (built from fed2022) predicts for that same
exclusion, vote-weighted.

## Headline

**Vote-weighted absolute flow error: 7.66 points** across 2,606
exclusion-destination rows.

By which rung of the fallback chain supplied the rate:

| source | rows | votes | weighted MAE |
|---|--:|--:|--:|
| exact cell | 2,236 | 15.4M | **7.18** |
| superset cell | 318 | 1.8M | 9.40 |
| pairwise | 49 | 0.36M | 17.66 |
| none (pooled) | 3 | 0.04M | 28.24 |

The fallback chain is working as intended — error rises monotonically as the
evidence gets thinner. But **even exact cells carry 7.18 points**, which is
the more important finding: flows genuinely move between elections, and no
amount of better cell-matching fixes that.

## The largest biases

| flow | actual | predicted | bias | votes |
|---|--:|--:|--:|--:|
| **ONP -> LNP** | 61.6 | 51.1 | **−10.5** | 1.46M |
| ONP -> IND | 35.5 | 43.3 | +7.8 | 0.31M |
| ONP -> GRN | 17.7 | 24.8 | +7.1 | 0.81M |
| ONP -> ALP | 20.0 | 24.4 | +4.4 | 1.44M |
| IND -> ALP | 45.0 | 39.8 | −5.2 | 0.69M |
| LNP -> GRN | 25.1 | 32.8 | +7.7 | 0.23M |

We systematically bleed One Nation preferences away from the Coalition and
into the Greens, Labor and independents. That is high-volume and it explains
the Coalition seats this model was under-confident on (Nicholls, Flynn,
Casey).

## It is DRIFT, not a derivation bug

The matrix reproduces its source election exactly — our pooled ONP row sends
47.6% to the Coalition, and fed2022's actual ONP row is 47.6%. The problem is
that fed2025 was 61.6%.

ONP -> LNP by election: 28.3, 33.9, 22.5, 47.4, **60.4**, **47.6**, **61.6**
(2007 to 2025).

It **oscillates** with whether One Nation directed preferences to the
Coalition that cycle. It is not a trend, so it cannot be extrapolated, and a
single prior election inherits whichever way the last one went.

## What was tried

**Pooling more prior elections.** Reduces raw flow error but makes the seat
forecast WORSE:

| priors | flow MAE | fed2025 log loss |
|---|--:|--:|
| fed2022 only | 7.66 | **0.3136** |
| fed2019 + fed2022 | **7.35** | 0.3200 |
| fed2016 + fed2019 + fed2022 | 7.52 | not run |

Refused. Averaging smooths a quantity that genuinely alternates, so the
average is wrong in a different way in every cycle. Kept as
`AUSPOL_FLOW_PRIORS`, off by default, because the audit result is worth
being able to reproduce.

Also note the guard this exposed: the harness asserted `all(tx$election ==
ea)`, which pooling breaks. Generalised to "strictly before the target
election" rather than removed, so the leakage protection survives.

## What would actually fix it

One Nation's **how-to-vote cards**, published before polling day. The
oscillation is a preference-deal decision, not a behavioural drift, and it is
knowable in advance — we simply do not hold that data. Same shape as the
seat-polling conclusion: the remaining error is information we have not
acquired, not a parameter we have mis-set.

## Two more flow ideas, both refused (2026-09-05)

**Per-class pooling by volatility.** Pooling every class across two priors
hurt, but volatility differs enormously between classes and is measurable
from PRIOR elections only (fed2013-2022, nothing from the target):

| class | vote-weighted sd of destination shares |
|---|--:|
| ONP | 13.59 |
| ALP | 12.82 |
| LNP | 7.92 |
| OTH_RIGHT | 4.88 |
| OTH | 3.55 |
| IND | 3.47 |
| GRN | 0.61 |

So "average more where the estimate is unstable, stay recent where it is
not" -- ordinary shrinkage, with the class ranking decided without touching
fed2025. Implemented as `AUSPOL_FLOW_POOL_VOLATILE`. **Refused: 0.3045
against 0.3036.** Kept off by default and documented, because the volatility
table is worth having and the negative result should not need re-deriving.

**Recent state elections as a flow source.** Pete's idea, and a good one:
Western Australia voted in March 2025 and Queensland in October 2024, both
BEFORE fed2025 in May, so their transfers carry One Nation's current
preference posture in a way fed2022 cannot. The machinery already existed
(`pool_external_flows()`, `AUSPOL_WA_FLOWS` / `AUSPOL_QLD_FLOWS` /
`AUSPOL_SA_FLOWS`, already date-cutoff aware from the WA-flows
pre-registration). **Refused: 0.3171 against 0.3036** -- state flows carry
enough jurisdiction-specific behaviour to outweigh their recency.

Both were aimed at the same target: ONP -> LNP drift, which remains the
largest single flow error and the whole of the remaining deficit to AE
Forecasts (Coalition seats +4.04; independents are now NEGATIVE at −1.02 and
Labor −2.67, i.e. this model now beats AEF on both).
