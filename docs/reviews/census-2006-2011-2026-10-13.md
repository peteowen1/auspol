# Census 2006 and 2011 by electorate: what exists, what was fetched, what is left (2026-10-13)

Why it matters: Pete decided older elections must run the full published model, and seven census features sit in it.
Only the 2016 and 2021 census are on disk. This note says where 2006 and 2011 versions come from and what mapping is left.
No features were built and no existing file was touched. Items marked (unverified) were not checked against the files.

## 1. Current feature inventory (verified from `scripts/build_census_features.R`)

Seven features, all derived from ABS table G01 (age, birthplace, ancestry, language, schooling), computed by `derive()`:

| feature | definition | 2016/2021 source column |
|---|---|---|
| yr12_pct | Year 12 share of all who gave a highest-schooling answer | `High_yr_schl_comp_Yr_12_eq_P` over the sum of Yr 12/11/10/9/8-or-below |
| born_aus_pct | born in Australia, % of persons | `Birthplace_Australia_P` / `Tot_P_P` |
| indig_pct | Aboriginal or Torres Strait Islander, % | `Indigenous_P_Tot_P` / `Tot_P_P` |
| over55_pct | aged 55+ (55-64, 65-74, 75-84; 85+ not counted) | `Age_55_64_yr_P` etc. |
| under35_pct | aged 15-34 | `Age_15_19_yr_P`, 20_24, 25_34 |
| lang_other_pct | other language at home | `Lang_spoken_home_Oth_Lang_P` (SED) or `Lang_used_home_Oth_Lang_P` (CED) |
| edu_25plus_pct | persons 25+ attending an educational institution, % of all persons | `Age_psns_att_edu_inst_25_ov_P` |

No income feature exists, deliberately: the state reaggregations carry G01 only (build_census_features.R header).

Geography and vintage (files in `external/reference/census/`):

- State pairs: state electoral districts (SED), 2016 census reaggregated onto each boundary year via ABS SED correspondences
  (`census-sed-2016-reaggregated-to-{2021,2022,2024,2025}.csv`, joined by `final_name`). Every state pair before 2022 (vic2014/2018, nsw2019, qld2020, wa2001-2017, plus sa/others per `VINTAGE`) takes the 2021 reaggregation of the 2016 census.
- Federal pairs: Commonwealth electoral divisions (CED): fed2007, 2010, 2013, 2016 use `census-ced-2016.csv`; fed2019/2022/2025 use `census-ced-2021.csv`.
- Consumers: `output/census-features.csv` -> `R/education_residual.R`, `R/demographic_residual.R`, `scripts/fit_xgb_primary_v7.R` (census_f, z and rank variants), `scripts/fit_demographic_swing.R` (reads `census-sed-2021.csv` directly).

Finding to raise with Pete (verified): the code comment says "the census predates every election it is attached to", but
fed2007-fed2016 and every state pair before 2016 use the 2016 or 2021 census, which POSTDATES them. The 2006/2011 backfill
fixes this for old pairs as well as filling the 2000s.

## 2. What 2006 and 2011 provide (verified from the downloaded files unless marked)

| census | geography | products | rows | notes |
|---|---|---|---|---|
| 2011 | CED 2011 (the 150 divisions of the 2010 and 2013 elections), national file | Basic Community Profile (BCP) tables B01-B46, short header, CSV | 168 rows (150 divisions plus special areas) | ids `CED101...`; division names NOT in the zip |
| 2011 | SED 2011, national file | same BCP tables | 446 rows | ids `SED10001...`; names in `external/reference/boundaries/SED_2011/SED_2011_AUST.dbf` (`SED_NAME`) |
| 2006 | CED 2004 and CED 2007 (two boundary sets) | BCP tables B01-B45, per state folder, CSV | CED_2004: NSW 52, Vic 39, Qld 30, SA 13, WA 17, Tas 7, ACT 4, NT 4; CED_2007 present (counts not tallied) | names in `Census2006_geog_desc.xls` (levels CED, CED07) |
| 2006 | SED (2006 boundaries) | same | NSW 95, Vic 90, Qld 91, SA 49, WA 59, Tas 27, NT 27, ACT 4 (rows include some non-geographic rows, unverified) | names in `Census2006_geog_desc.xls` (level SED) |

The 2006 national "BCP" zip looks like it has only state and Australia geography. The electoral files are inside two nested zips
(`BCP_CGIA_06_R2.0.zip`); that is where CED_2004, CED_2007 and SED live. 2011 has no pre-2016 problem: ABS ships CED and SED directly.

Variable-by-variable answer (every current feature has a 2006 and 2011 answer):

| feature | 2011 CED | 2011 SED | 2006 CED/SED | table |
|---|---|---|---|---|
| yr12_pct | available | available | available | 2011 B16A/B16B; 2006 B16 (highest year of school by age by sex). Summing needs the cell lists. |
| born_aus_pct | available | available | available | 2011 B09 (`Australia_P`) or B01; 2006 B09 country of birth |
| indig_pct | available | available | available | 2011 B07 or B01; 2006 B07 |
| over55_pct | available | available | available | 2011 B01 age bands; 2006 B04 age by sex |
| under35_pct | available | available | available | same |
| lang_other_pct | available | available | available | 2011 B13 (`SOL_*`, English-only is `SEO_*`); 2006 B13 language spoken at home. Both have only the language list, so "other" = total minus English-only (and minus not-stated if the 2016 code did that, check). |
| edu_25plus_pct | available | available | available | 2011 B15; 2006 B15 (type of institution by age). 2016 used age-by-institution cells; confirm the 25+ cells exist at electorate level (unverified). |

Two comparability warnings (unverified): the ABS 2006 BCP was reissued 2008-02-29 to fix Table B02 for CED and SED only (unaffected
tables above); 2006 and 2011 category labels differ from 2016, so each feature's cell list must be written per census and
checked against national totals.

Bonus: both censuses carry table B02 (medians: personal, family and household income, mortgage, rent) at CED and SED level. The
income feature that was refused for the 2016 state files because reaggregation lacked G02 would be available directly for 2006
and 2011 state districts. Do not add it for only some vintages (jurisdiction-label risk in CLAUDE.md).

## 3. Mapping work: which election uses which census file

Boundary match is exact only where the election's divisions equal the census geography. Everything else needs reaggregation.

| elections | census and geography | match |
|---|---|---|
| fed2004 | 2006 CED 2004 | exact boundaries; census 2 years AFTER (2001 census not available in this task) |
| fed2007 | 2006 CED 2007 | exact (2007 redistribution); census 2006 precedes the election |
| fed2010, fed2013 | 2011 CED 2011 | boundaries of the 2010 redistribution: should be exact (unverified); census 2011 post-dates fed2010 and precedes fed2013; for fed2010 use 2006 CED 2007 reaggregated, or accept 2011 (decision for Pete) |
| fed2001 | none | CED 2004 or 2007 would be reaggregated; 2001 census not fetched |
| fed2016 | already on disk (2016 CED) | unchanged |
| state elections about 2006-2014 (Vic 2006/2010, NSW 2007/2011, Qld 2009/2012, SA 2006/2010, WA 2008) | 2006 SED / 2011 SED | exact when no redistribution since the census (Vic 2006 and 2010, NSW 2007 and 2011 likely); otherwise needs mapping (unverified per state) |
| state elections 2000-2005 and 2012-2018 with redistributions in between | 2006 or 2011 SED | needs mapping |

What the mapping needs:

1. 2011 to later (2014+ boundaries): ABS publishes ASGS 2011 non-ABS structures with mesh block allocations to SED 2011, and
   2016 to 2021 SED correspondences are already on disk (`correspondences/abs-sed/`). A direct SED 2011 to SED 2016 file was not
   found on the current ABS page (search found only an archived 2011-to-2016 main-structure file, in xls); likely route: mesh-block
   or SA1 2011 population-weighted allocation, then onto the election boundary (unverified that suitable files exist).
2. 2006 SED has no ASGS successor. The 2006 digital boundaries ARE fetched (below), so an area-overlap reaggregation of the
   2006 SED polygons onto each older election's boundaries is possible without collection districts. Population-weighted would
   need collection district data (the ASGC zip has CD-level BCP, 577 tables per geography); areal weighting is the cheap option.
3. Election boundary files for the older state elections (pre-2013) are NOT on disk and not sourced here (state commission sites);
   these are the real dependency. Federal divisions: AEC historical boundaries (not fetched).
4. Names: 2011 CED names are missing from the zip; fill from the 2010-election division list (AEC), or the 2006 CED07 list
   for the same divisions (check). 2006 SED and CED names are in the geog description spreadsheet but its codes did not read as numeric, so check the code-to-name join first.
5. Territories and Tasmania are included in the files (ACT, NT, Tas), which helps the Tas/NT/ACT scoping work.

URLs (live 2026-10-13): `https://www.abs.gov.au/census/find-census-data/datapacks/download/2011_BCP_{CED,SED}_for_AUST_short-header.zip`;
2006 files from `https://www.abs.gov.au/websitedbs/D3310114.nsf/home/2006%20Census%20Datapacks` (links `census06bcp.zip`,
`census06cgia2.zip`). Plain curl, no login, 3 s between 2011 requests, no email in the User-Agent. Nothing already on disk was refetched.

Not fetched: 2011 digital boundaries for CED (SED 2011 shapes are already in `boundaries/SED_2011/`); 2011 TableBuilder
(login) and 2001 census; 2011 and 2006 SA1 or collection-district tables (not needed unless population-weighted mapping is chosen);
state election boundary files.

## 5. Gaps and effort

Every current census variable is available for 2006 and 2011 at CED and SED. No variable is blocked.

| step | effort |
|---|---|
| Build `census-ced-2006/2011` and `census-sed-2006/2011` CSVs with the G01-equivalent columns (cell lists per census, totals check) | about half a day |
| Name joins (2011 CED names, 2006 name codes) | 1-2 hours |
| Federal pairs fed2004/2007/2010/2013: exact CED mapping, add to `VINTAGE`-style tables and `census-features.csv` | about half a day |
| State pairs with unchanged boundaries (likely Vic 2006/2010, NSW 2007/2011) | 1-2 hours once names are matched |
| State pairs needing reaggregation (2011 to 2014+ boundaries; 2006 SED to older boundaries): needs election boundary files first | 2-3 days including sourcing the boundaries; the dependency is on the coverage program's results work |
| Optional B02 income feature for 2006 and 2011 (only worth it if the 2016 and 2021 state side gets G02 too) | 0.5 day plus the 2016 reaggregation |

Decisions for Pete: (a) use the census that precedes each election (2006 for fed2004/2007/state 2007-2010, 2011 after),
instead of the current 2016/2021 for old pairs; (b) whether fed2001 and state 2000-2002 take the 2006 census (five or more years later) or wait for a 2001 census fetch.
