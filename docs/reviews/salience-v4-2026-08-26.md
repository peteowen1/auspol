# Cross-seat batching: AUC 0.971 on the full federal 2022 field

2026-08-26. Supersedes `salience-emergence-2026-08-26.md` (AUC 0.841) — same
signal, a measurement method rebuilt four times.

## The checks that make it believable

A result that *improved* when the sample got harder (0.954 on 49 strong seats →
0.971 on all 151) needs scrutiny, not celebration.

**It is not an artefact of zeros.** 79 of 151 sit at zero, so the obvious worry
is that the AUC is measuring missingness:

| | |
|---|---|
| winners with jump ≤ 0 | **0 of 14** |
| losers with jump ≤ 0 | 79 of 137 |
| **AUC among non-zero rows only** | **0.932** (14 v 58) |

**Every non-major winner had a positive campaign jump**, and the signal still
scores 0.932 with the zeros removed entirely.

**The chain does not explode.** 38 chained rescales, range −5.03 to 57.64,
median 0.00. Negative values are real and plausible: a name quieter during the
campaign than before it.

## What it took, and what each fix was worth

Four rebuilds, and **three of the four faults were caught by Pete checking
Google by hand or asking a question I had assumed away**:

| fault | effect |
|---|---|
| legal name, not search form | Tink **0.000 → 1.479** |
| daily buckets below Google's publishing threshold | Chandler-Mather **0.000 → 3.46** |
| hyphen retained | Chandler-Mather **3.46 → 9.99** |
| per-state geo | imported a state-size effect |
| PM calibration | **caused** the cross-seat gap it was built to fix |
| per-seat queries | not comparable: Dai Le **8.25 alone vs 17.50** in a shared query |
| `ratio` and `rise` | both LOST to `jump` (0.880, 0.857 against 0.921) |

The hyphen case is the sharpest methodological lesson: tested on daily buckets
it made no difference, because everything was floored at zero. **A null result
under one condition does not clear a variable under another**, and that
conclusion was carried forward into a regime where it was false.

## Known flaw, not yet fixed

**The one-per-seat pick misses 4 of 18 winners**: Bob Katter, Marion Scrymgour,
Luke Gosling and **Adam Bandt**. Melbourne runs a no-hope independent, and
ranking IND above GRN unconditionally queried them instead of the sitting Greens
MP.

The fix — pick by the previous election's non-major vote, which is leak-free —
is written and committed but not yet run: it creates new keyword sets, so
nothing is cached, and Google throttled before the first batch. **The reported
0.971 therefore stands on a corpus missing four winners**, and recovering them
should be neutral-to-favourable rather than the reverse.

## Limits

- **One election.** fed2022 is the teal wave — the most favourable possible
  test. fed2019 and fed2025 are untested with this method.
- **Every figure is a single pull.** The literature wants replicates.
- **Nothing tests Victoria**, the live target.
- **This still does not make the model better.** It ranks; turning a rank into
  a hazard is `docs/plans/prereg-salience-surge-hazard.md`, and the pre-
  registered gate — the six named seats above a mean of 0.10 — is unscored.
