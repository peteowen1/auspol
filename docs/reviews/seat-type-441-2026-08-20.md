# Seat type is real, stable, and still redundant — now with enough power to say so

Run 2026-08-20 against
[../plans/prereg-seat-type-441.md](../plans/prereg-seat-type-441.md), committed
before anything was fitted.

**Verdict: KEEP A. B is +0.37 SE — the wrong direction, nowhere near the −2 SE
bar.**

## The null is stronger than the pre-registration promised

The plan computed in advance that the test could not detect anything smaller
than a **9% improvement** (2 SE = 0.28 MAE), and recorded that a null would
therefore rule out only a large effect.

The run's own clustered SE came out at **0.0840**, so the real bar was
**0.168 MAE — 5.2% of baseline error**. The test was better powered than
promised, not worse. That is the first time in this repo a tolerance has been
sized in advance and turned out conservative rather than useless.

**What is ruled out: any effect larger than 5% of baseline error. What is still
not ruled out: anything smaller.**

## Seat type is a real gradient — it is redundancy, not noise

Pooled across all five elections, deviation from each cycle's statewide swing:

| type | seats | mean deviation | sd |
|---|---:|---:|---:|
| inner-metro | 115 | **+1.12** | 3.79 |
| outer-metro | 146 | +0.11 | 4.37 |
| provincial | 107 | −0.32 | 3.98 |
| rural | 73 | **−1.53** | 4.83 |

And every seat-type coefficient **holds its sign across all five folds** (R2
passes), ranging from −0.05 to −2.81 against inner-metro. This is not a variable
flailing at noise. It carries information; `fed_swing` already has it.

## The result that was not the question

| arm | pooled leave-one-election-out MAE |
|---|---:|
| uniform swing (no model at all) | 3.2160 |
| **A — `fed_swing` alone** | **3.1767** |
| C — seat type alone | 3.1931 |
| B — both | 3.2115 |

**On these five elections the transposed `fed_swing` beats doing nothing by
1.2%.** Seat type alone gets within a whisker of it. On the two elections with a
*published* `fed_swing`, the same adjustment gained 15%.

Two things could produce that gap and this test separates neither:

- the transposed measure is noisier than the published one, which was already
  measured at +1.86 SE;
- the five-election set includes **Queensland 2020, baseline MAE 1.676**, an
  almost perfectly uniform election that drags the pooled baseline down and
  leaves less for any predictor to win.

Both are probably true. **Untested, and it should not be quoted as evidence
against the live `SEAT_SWING_COEF` until it is** — the live model uses the
published measure, which is not what was scored here.

## R4 fired, quietly and in the losing direction

| election | baseline dispersion | gain from adding seat type |
|---|---:|---:|
| **qld2020** | **1.676** | **+0.314** |
| vic2018 | 3.153 | −0.088 |
| vic2022 | 3.351 | +0.135 |
| nsw2019 | 3.399 | −0.111 |
| nsw2023 | 4.508 | −0.097 |

The one election where seat type helps meaningfully is the low-dispersion one —
the case R4 was written to catch. It does not change the verdict, because the
pooled result loses anyway. It is recorded because R4 exists to be checked
whether or not it changes anything, and because **Queensland 2020 has now
behaved differently from the other four elections in three separate tests
today.**

## What was checked and passed

- **R1** — dropping any single election leaves the gain between −0.69 and +0.67
  SE. No election carries the result.
- **R2** — sign-stable across all five folds.
- **R5** — all **88 of 88** Victoria 2026 seats have a type, so the feature
  *could* have been applied. It is not being adopted on the merits, not on a
  technicality.

## Where this leaves the demographics question

The earlier review said the case for demographics should be made against
transposed federal data as the baseline, and that the seat-type result was
"suggestive, not established" at 180 seats.

It is established now, at the 5% level: **a four-way rural/metro taxonomy adds
nothing to a direct measurement of how the same voters actually voted.** That is
still one coarse categorical, and the correction in the earlier review stands —
this says nothing about continuous demographic variables, which was the thing it
was wrongly generalised to this morning.
