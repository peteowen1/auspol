# Negative result: seat type does not predict seat swing

2026-08-16. Tested before adopting, because `seat-types.csv` was sitting in the
anchor's data unused and looked like a free improvement.

## The tempting version

Victoria, 2022, 88 seats, in-sample. Regressing each seat's swing deviation
(its swing minus the statewide swing) on seat type:

| Model | residual sd |
|---|---:|
| intercept only | 3.989 |
| type only | 3.636 |
| region only | 3.363 |
| region + type | **3.136** |

Type adds over region at **F = 5.47, p = 0.0061**. On that alone it looks
adopted.

## Out of sample it is nothing

Federal has three seat files, so the same question can be asked
leave-one-**election**-out — leaving one *seat* out would leak its own
election, since seats in a cycle share the national swing. 451 seat-cycles
across 2019, 2022 and 2025:

| Model | LOO MAE | RMSE |
|---|---:|---:|
| **intercept only** | **5.7623** | 6.7463 |
| type | 5.7589 | 6.7984 |
| region | 5.8641 | 6.9533 |
| region + type | 5.8685 | 7.0061 |

**Nothing beats the intercept.** Type is worth 0.0034 MAE — 0.06%, and it
*loses* on RMSE. Region is actively worse than assuming every seat swings the
statewide amount.

The Victorian result was three extra parameters fitted to 88 points, and it
did not survive contact with a sample five times larger.

## Why this matters beyond one CSV

**It independently confirms an earlier finding by a different route.** The
regional analysis found that region effects correlate only 0.27 between 2018
and 2022 — which region swings hardest is not forecastable from last time.
This says the same of seat type, and adds that *region itself* fails out of
sample as a predictor.

That is consistent with how `simulate_seats()` already works: it draws a
regional effect **fresh** each simulation rather than predicting one. That
design was right, and now has a second line of evidence behind it.

## The general lesson, again

An in-sample F-test on 88 points endorsed a predictor that a proper
out-of-sample test found worthless. Held-out error has now overturned an
in-sample result twice today: here, and when leave-one-out endorsed a linear
trend for preference flows that the temporal backtest ranked sixth of eleven.

**Not adopted.** `seat-types.csv` stays unread, and now for a measured reason
rather than an unexamined one.
